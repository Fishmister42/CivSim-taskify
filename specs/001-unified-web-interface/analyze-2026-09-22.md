## What this pass looked for, and why

The 2026-09-21 pass found nine gaps behind a green suite and named their shape:
*a check written from the same mental model as the code inherits that model's blind spot*.
Re-running that same lens would mostly re-find its own fixes. This pass instead audited the
three places that class of defect **migrates to** after the checks are widened:

1. **Artifacts that assert a number the code computes.** A documented figure is a check with
   no test behind it; it goes stale silently the first time the computation's input grows.
2. **In-code prose that instructs a future contributor.** A docstring telling someone to delete
   a Protocol is load-bearing in the same way a test is — and unlike a test, nothing fails when
   it becomes wrong.
3. **Cross-deliverable statements made before the other deliverable landed.** 003 landed on
   2026-09-21, after most of this feature's prose was written.

All three produced findings. Every one below was **observed**, not inferred: the counts in A1
come from running `uv run civsim-web doctor` at this head, and A3's from counting the shipped
YAML.
